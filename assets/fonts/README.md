# Interface fonts

- Almendra Regular: titles, navigation and building names.
  Source: https://github.com/google/fonts/tree/main/ofl/almendra
  SIL Open Font License 1.1: `Almendra-OFL.txt`.
- EB Garamond variable (400–800), weight 500: figures and reading text.
  Source: https://github.com/google/fonts/tree/main/ofl/ebgaramond
  SIL Open Font License 1.1: `OFL.txt`.

Both fonts are bundled locally and included in the web export.
