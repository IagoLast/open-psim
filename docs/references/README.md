# Referencias vigentes

- `asset-style-reference.png`: referencia principal para geometría, proporciones,
  paleta y nivel de detalle de todos los modelos Blender.
- `houses-reference.png`: doce variantes de vivienda; piedra, tejados, porches y balcones.
- `wells-reference.png`: doce pozos; brocal hueco, cantería, cubo y estructura de madera.
- [`pontevedra-stone-reference.png`](pontevedra-stone-reference.png): fotografía de
  Pontevedra aportada por el usuario el 6 de septiembre de 2026. Referencia de color
  para granito cálido arena/gris beige, pavimentos y humedad localizada; prevalece
  sobre la paleta anterior para la piedra. No es una referencia de reconstrucción histórica.
- [`../design-style.json`](../design-style.json): prompt de diseño completo
  `pontevedra_low_poly_v1`, guardado con todos los valores proporcionados por el usuario.
- `idea_3.png`: composición de la interfaz de pergamino.
- `menu-top-reference.png`, `build-cost-reference.png`: recursos y costes de UI.

Las referencias se usan para orientar el trabajo; no se recortan para fabricar
assets ni se empaquetan dentro del juego. La malla y los renders son originales.
Las antiguas direcciones de pizarra oscura han sido retiradas.
